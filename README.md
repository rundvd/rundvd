# David Rundus

I’m a mechanical engineering Honors student at Baylor University interested in computational modeling, aerospace, and data-driven design. I enjoy using code and measurements to turn open-ended questions into testable problems.

## Selected work

- **Finite-range prime ranking:** Directed an exploratory study combining bounded-sieve arithmetic, Ulam-derived geometry, and binary quadratic form features. Compared ranking models in two test windows and documented the results in a 17-page manuscript.
- **Acoustic measurement and equalization:** Measured frequency response with a calibrated microphone, cleaned and interpolated the data in Python, and generated equalization settings for a custom target curve.
- **Urban heat island mitigation:** Wrote a literature review of 17 sources, comparing green infrastructure and reflective surfaces across thermal performance, cost, energy, and implementation tradeoffs.

## Current focus

Engineering mechanics, programming, and flight dynamics with Astro at Baylor. My tools include Java, plus foundational Python, MATLAB, and VPython.
